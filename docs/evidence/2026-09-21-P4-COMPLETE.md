## Shared checkpoint convention

Every project worker uses the same durable checkpoint shape:

- `version`
- monotonic `sequence`
- provider-neutral `cursor`
- source-domain `watermark`
- `last_success_at`
- optional deterministic `input_fingerprint`
- optional deterministic `output_fingerprint`

Provider-specific identifiers are rejected from checkpoint state by the validator.

## Shared heartbeat convention

Every project worker uses the same heartbeat shape:

- `status`
- `observed_at`
- `last_success_at`
- `consecutive_failures`
- provider-neutral `run_id`
- short non-secret `detail`

Allowed statuses are `ready`, `running`, `healthy`, `degraded`, `blocked`, `stopped`, and `maintenance`.

## RELIS reuse proof

`state/workers/RELIS.json` defines the `regional-state-observer` using exactly the canonical checkpoint and heartbeat contract. It is intentionally runtime-provider-neutral (`provider: unbound`) and explicitly sets `requires_vps: false` and `conoha_dependency: false`.
